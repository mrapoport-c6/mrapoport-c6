## 🚀 Getting Started

### Local Development
```bash
# Clone the repository
git clone https://github.com/mrapoport-c6/mrapoport-c6.git
cd mrapoport-c6

# Start the server (Option 1: Python)
python3 server.py

# Start the server (Option 2: Supervisor)
pip install supervisor
supervisord -c supervisord.conf

# Open in browser
open http://localhost:8000
```

### Deployment Options
- **Static Hosting**: Deploy to Netlify, Vercel, or GitHub Pages
- **Docker**: Containerized deployment with nginx
- **Cloud**: AWS S3, Google Cloud Storage, or Azure Static Sites
- **CDN**: CloudFlare or AWS CloudFront for global distribution
